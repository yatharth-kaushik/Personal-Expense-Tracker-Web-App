## 📌 About the Project

The **Personal Expense Tracker Web App** is a browser-based financial management tool developed using HTML, CSS, and Vanilla JavaScript.

It helps users record and manage expenses, understand their spending habits, monitor monthly expenses, and visualize category-wise spending through an interactive dashboard.

The application uses browser LocalStorage to save expense records and theme preferences, so no backend server or database setup is required.

## ✨ Features

- 📊 **Interactive Dashboard** — View total spending, current-month expenses, expense count, and average expense.
- ➕ **Add Expenses** — Record new expenses and their details.
- ✏️ **Edit Expenses** — Update existing expense records.
- 🗑️ **Delete Expenses** — Remove unwanted transactions.
- 🔍 **Search and Filter** — Find expenses by ID, category, or description.
- 📅 **Date-Based Filtering** — Filter expenses by month, year, and amount range.
- 📈 **Spending Analytics** — Analyze category-wise expenses using a donut chart.
- 🧾 **Monthly Summary** — Review spending totals, average expenses, highest and lowest expenses, and yearly monthly totals.
- 🕒 **Recent Transactions** — View recent expenses and frequently used categories.
- 🌙 **Dark Mode** — Switch between light and dark themes.
- 📥 **CSV Export** — Export expense records for spreadsheet analysis.
- 📱 **Responsive Interface** — Designed for desktop and smaller screens.
- 💾 **Local Data Storage** — Preserve expenses between browser sessions using LocalStorage.

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### Prerequisites

- A modern web browser such as Google Chrome, Microsoft Edge, or Firefox.
- Git (optional, for cloning the repository).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/yatharth-kaushik/Personal-Expense-Tracker-Web-App.git
```

**2. Navigate to the project directory**

```bash
cd Personal-Expense-Tracker-Web-App
```

**3. Open the application**

Open `index.html` in your preferred web browser.

That's it! No package installation, build process, or backend configuration is required.

## 💾 Data Storage and Privacy

The application uses the browser's **LocalStorage** to save expense data and theme preferences.

- Data is stored locally in the browser.
- Expenses do not automatically synchronize across devices or browsers.
- Clearing browser site data may remove saved records.
- No backend server or user account is required for the core application.

**Recommendation:** Export your expenses regularly to maintain a separate backup.
