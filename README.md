## 📌 About the Project

**Personal Expense Tracker Web App** is a browser-based financial management tool built with **HTML, CSS and Vanilla JavaScript**.

Record your expenses, understand your spending habits, monitor monthly totals, and visualize category-wise spending on an interactive dashboard. Everything is saved in your browser using **LocalStorage**, so there's **no backend, no database and no setup**.

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Edge or Firefox)
- Git *(optional, for cloning)*

### Installation

**1️⃣ Clone the repository**

```bash
git clone https://github.com/yatharth-kaushik/Personal-Expense-Tracker-Web-App.git
```

**2️⃣ Go to the project folder**

```bash
cd Personal-Expense-Tracker-Web-App
```

**3️⃣ Open the app**

Open `index.html` in your browser.

> 💡 That's it! No package installation, build process or backend configuration is required.

## 📖 How to Use

1. Open the app in your browser.
2. Add an expense using the expense management interface.
3. Review your financial statistics on the dashboard.
4. Search for transactions or apply filters to find specific records.
5. Explore monthly summaries and category-wise analytics.
6. Switch between light and dark themes.
7. Export your expenses as a CSV file whenever you need.

---

## 🔒 Data Storage & Privacy

> Your data **never leaves your browser**.

- 🗄️ Data is stored locally using the browser's **LocalStorage**.
- 🔄 Expenses do not sync across devices or browsers.
- ⚠️ Clearing browser site data may remove saved records.
- 👤 No backend server or user account is required.

**💡 Tip:** Export your expenses regularly to keep a separate backup.
